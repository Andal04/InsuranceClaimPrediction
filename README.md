***Insurance Claim Approval Prediction***

Predict whether an insurance claim will be **approved or denied** using machine learning. This project helps insurance providers assess risk and improve decision-making through predictive analytics.

***Project Objective***

- Creating a predictive model which will help the insurance marketing team
to know which customer will buy the product.
- Suggestions to the Insurance market team to make customers buy the
product

***Project Workflow**

- Data Loading & Cleaning
- Handle missing or inconsistent values
- Convert data types and normalize formatting
- Exploratory Data Analysis (EDA)
- Visualize distributions and categorical counts
- Analyze relationships between features and claims
- Detect class imbalance
- Feature Engineering
- Encode categorical variables (Label/One-Hot Encoding)
- Scale numerical features

***Model Building***

- Train/test split with stratification
- Implement multiple classification algorithms
- ***Model Evaluation***
 - **Use metrics such as**:
 - Accuracy
 - Precision, Recall, F1-Score

***Model Comparison & Selection***
- Compare model performance using cross-validation
- Select the best model based on generalization capability

***Models Implemented***
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting (XGBoost)
- Support Vector Classifier (SVc)

***Tools & Libraries***
- Python
- Libraries: Pandas, NumPy, Scikit-learn, XGBoost, Seaborn, Matplotlib
- IDE: Jupyter Notebook
